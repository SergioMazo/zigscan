# Public demo data

`demo-synthetic-join.pcap` contains deterministic synthetic IEEE 802.15.4
frames. It was generated by `tools/generate_demo_pcap.py`; it was never received
from the air and has no relationship to a customer, lab or persistent network.

The PAN, extended PAN, short addresses, payload and encrypted-looking bytes are
fictional. One synthetic EUI-64 starts with Control4's publicly assigned
`00:0f:ff` OUI so the census can demonstrate vendor detection; the remaining
five bytes are generated from the demo seed and do not identify a real device.
Other EUI-64 values are locally administered. The sample includes beacons,
association commands, data requests, ACKs and data frames so both Analysis and
census have useful content before a user owns hardware.

Regenerate it from the repository root with:

```bash
python3 tools/generate_demo_pcap.py
```

The author's real laboratory join capture, formerly named
`demo-zigbee-join.pcap`, is deliberately not distributed. Customer captures and
captures from persistent lab networks must never be added here.
